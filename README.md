
# Bonjour My French 🇫🇷

A web project designed to support French language learning through structured lessons and focused practice.

## Features

- Structured French lessons
- Focused language practice
- Learning materials for various levels
- Flexible, self-paced learning

## Tech Stack

### Frontend
- React
- Vite
- HTML
- CSS
- JavaScript

### Planned
- Backend: To be decided
- Database: To be decided

## Getting Started

### Prerequisites
- Node.js
- npm

### Installation

```bash
cd frontend
npm install
npm run dev
```

Open the local URL displayed in your terminal to view the website.

## Build

```bash
npm run build
```

The production files will be generated in `frontend/dist/`.
