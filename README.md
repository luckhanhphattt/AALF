
# AALF 🇫🇷

A web project designed to support French language learning through structured lessons and focused practice varied from level A1 to C1 with all-rounded skills (Reading, Listening, Writing, Speaking).

## Features

- Structured French lessons
- Focused language practice
- Learning materials for various levels
- Flexible, self-paced learning

## Getting Started

### Prerequisites
- Node.js
- npm

### Installation

```bash
cd frontend
npm install
npm run dev
```

Open the local URL displayed in your terminal to view the website.

## Build

```bash
npm run build
```

The production files will be generated in `frontend/dist/`.
